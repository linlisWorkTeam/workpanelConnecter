# WorkPet 状态动图「定制」— 设计稿

> 文档状态：已实现的设计记录；当前使用说明见 `apps/workpet/README.md`。

> 日期：2026-08-19  
> 状态：**已批准**  
> 相关：`docs/superpowers/specs/2026-08-19-workpet-live2d-swap-design.md`（双模式、四文件皮肤约定）

WorkPet **不接任何生图 API**。用户在别的平台用参考图 + 本 prompt 出 zip；桌宠只负责复制 prompt 和解包加载。

## 1. 已锁定决策

| # | 决策 |
|---|------|
| C1 | 参考图由用户自备（自拍、立绘均可）；WorkPet 不提供四宫格模板 |
| C2 | zip 与现有文件夹皮肤同一契约：`idle` / `thinking` / `speaking` / `error`，扩展名 `gif` / `webp` / `png` / `svg`；缺的回退 idle |
| C3 | 状态动图模式菜单增加两项：「复制定制 prompt」「加载压缩包…」；「上传动图文件夹…」保留 |
| C4 | Live2D 模式不显示这两项 |
| C5 | 解压到 `~/.workpet/skins/<包名>/`，写入 `pet.mode = sprite` 与 `pet.spriteSkin`；换形象与登录无关 |
| C6 | 拒绝路径穿越、单包未压缩 ≤32MB、条目 ≤32；忽略非四态文件；不执行 zip 内任何脚本 |
| C7 | 失败只气泡提示，不改当前皮肤、不影响聊天 |

## 2. 右键菜单（状态动图）

```text
右键角色
├─ 形象 · Live2D
├─ 形象 · 状态动图          ●
├─ （当前模式下列出的皮肤）
├─ 上传动图文件夹…
├─ 复制定制 prompt
└─ 加载压缩包…
```

- **复制定制 prompt**：把第 4 节全文写入剪贴板；气泡「已复制。带上一张参考图，到任意生图平台按说明出 zip」。不打开浏览器、不选文件。剪贴板失败则把同一段写入 `~/.workpet/sprite-customize-prompt.txt`，气泡提示去该文件复制。
- **加载压缩包…**：选 `.zip`；取消则什么都不做。成功后立刻换上该皮肤。

## 3. 加载压缩包

1. 包名 = zip 文件名（走现有 `sanitize_id`）；非法则用 `skin`。已有同名目录则覆盖。
2. 先解到临时目录，校验通过再写入 `~/.workpet/skins/<包名>/`。
3. 允许根目录四文件，或只套一层文件夹。只提取 `idle|thinking|speaking|error` + `gif|webp|png|svg`（大小写不敏感，落盘小写）。
4. 至少一张能当 idle 的图（任一状态也可，四态共用），否则整包拒绝。
5. 拒绝：`..`、绝对路径、超 32MB 未压缩、超 32 个条目、不是 zip。
6. 之后复用现有 `list_sprite_skins` / `sprite_frames`，与文件夹上传同一套加载。

## 4. Prompt 正文（常量，勿按平台改写）

```text
你是桌宠皮肤打包助手。用户会附带一张参考图（自拍或立绘）。请严格按该图的脸、发型、服饰，生成一只可做桌面宠物的角色，并打成一个 .zip。

硬性要求：
1. zip 根目录（或只套一层文件夹）必须包含以下小写文件名，优先用循环动图：
   - idle.gif（或 .webp / .png）：待机，轻微呼吸或眨眼
   - thinking.gif：思考，例如歪头、看向一侧
   - speaking.gif：说话，口型或身体轻晃
   - error.gif：出错，愣住或冒汗，不要恐怖、不要流血
2. 透明背景；角色完整入画；不要边框、水印、字幕、四宫格或精灵表。
3. 四张必须是同一只角色、同一套衣服、同一构图（全身或半身保持一致）。画布 512×512 或 768×768。
4. 每段动图约 1–2 秒循环。不要只给一张预览图。
5. 不要 README 或其它文件名。缺文件会导致桌宠无法加载。

只输出这一个可下载的 zip。
```

单测断言该字符串包含 `idle`、`thinking`、`speaking`、`error` 和 `.zip`。改措辞只改常量。

## 5. 测试

- 菜单：sprite 模式含「复制定制 prompt」「加载压缩包」；live2d 模式不含。
- Prompt 常量含四态文件名与 `.zip`。
- 解包：根目录四文件成功；一层子目录成功；含 `../` 的条目拒绝；空包 / 无图片拒绝；无关文件忽略且仍能加载。
- 不解真实生图站、不测网络。

## 6. 非目标

- 不调用、不内置任何生图平台。
- 不提供参考图模板、不把 zip 当 Live2D。
- 不替换「上传动图文件夹」。
