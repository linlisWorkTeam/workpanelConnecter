# WorkPanelConnecter v0.2.0

Date: 2026-08-22

This release turns the previous site-local Relay/Runner bridge into a locally verified Connecter federation release candidate.

## Highlights

- Formal topology: one Connecter per Site and one central Connecter Host; WorkPet, WorkPanel and Runner execution remain Site-local.
- Durable cross-Site command/result flow through Host with inbox/outbox recovery, TTL, leases, fencing, idempotency and first-terminal-wins semantics.
- Stable Subject, GroupRef, message, correlation and trace identifiers plus Directory v2 projection and explainable routing.
- Runner protocol v2 leases and result IDs, isolated v1 compatibility, crash reclaim, operator requeue/cancel and dead-letter handling.
- Enrollment approval, scoped device credentials, credential rotation/revocation, optional device-credential-only production mode, and audited Host peer credential rotation/revocation.
- Signed federation envelopes, external signing-key sources, HTTPS/mTLS client material, default-deny multidimensional policies, quotas and disk backpressure.
- Structured logs, health/trace/security views, append-only audit archive, migrations with backup/rollback, backup/restore and incident runbooks.

## Verification

- `npm run test:release-local`: all 48 fail-fast local gates passed.
- Independent 600,000 ms repeated three-process federation soak passed (`FEDERATION_SOAK_OK`, wall time 602.4 s).
- Current live WorkPanel canary on `127.0.0.1:8082` passed health, membership, no-@ admin routing and explicit @Agent dispatch (`E2_AT_MENTION_OK`).

## Upgrade notes

- SQLite schema advances through migrations 001-012. Back up the database and configuration before upgrade; do not downgrade the schema in place.
- Production Sites should use `federation.requireTls`, message signatures with external secret sources, device credentials for Runners, and exact allow policies before enabling cross-Site traffic.
- Host peer config tokens bootstrap first registration. After registration, the durable Host credential record is authoritative; use the audited ops revoke/rotate endpoints for incident response.

## Evidence boundary

This is a release candidate, not a production-readiness claim. Real two-Site plus independent-Host TLS/mTLS acceptance, external alert integration and the 72-hour soak remain deployment-environment gates.
