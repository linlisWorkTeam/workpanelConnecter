# WorkPanelConnecter v0.2.1

Date: 2026-08-22

Patch release adding executable TLS evidence to the v0.2.0 federation release candidate.

## Changes

- Add `test:mtls-handshake`, which generates an ephemeral CA plus server/client certificates with OpenSSL.
- Complete a real HTTPS mutual-TLS request through the production federation client and verify the peer certificate identity.
- Verify a request without the client certificate is rejected during TLS negotiation and never reaches the application handler.
- Include the handshake in the fail-fast local release suite, increasing it from 48 to 49 gates.

## Verification

- `npm run test:mtls-handshake` -> `MTLS_HANDSHAKE_E2E_OK`.
- `npm run test:release-local` must pass 49 gates before publishing this patch.

## Evidence boundary

The handshake is real but local and ephemeral. Real two-Site plus independent-Host network behavior, production certificate issuance/rotation, external alert integration and the 72-hour soak remain deployment gates.
