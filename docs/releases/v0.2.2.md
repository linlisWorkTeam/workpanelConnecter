# WorkPanelConnecter v0.2.2

Date: 2026-08-22

Windows binary delivery release. This patch turns the source-only v0.2.1 release into downloadable, smoke-tested Windows artifacts.

## Artifacts

- `WorkPet_0.2.2_x64-setup.exe`: one-click NSIS installer for the WorkPet desktop application.
- `WorkPanelConnecter_0.2.2_win-x64-portable.zip`: self-contained Site Connecter using the Node.js Single Executable Application format; Node.js does not need to be installed separately.
- `SHA256SUMS.txt`: SHA-256 checksums for both downloads.

## Build and verification

- Enable Tauri NSIS bundling for WorkPet.
- Bundle the Connecter relay and inject it into a pinned Node 24 executable using SEA.
- Keep migrations and schema as explicit portable resources beside the executable.
- Start the packaged Connecter against an isolated configuration and require `/v1/health` to return `ok: true`.
- Install WorkPet silently into an isolated temporary directory and verify the installed executable remains running.
- Run the 50-gate local release suite before publishing.
- Build and upload the same artifacts on `windows-2022` for every `v*` tag.

## Security boundary

The binaries are not Authenticode-signed yet. Windows SmartScreen may show an unknown-publisher warning. Production configuration, TLS keys and credentials are never embedded in the portable package; operators must create `config/relay.json` or set `CONNECTER_RELAY_CONFIG`.
